# 个人工作站控制台（停止开发，源码归档）

Android 浏览器上的个人电脑控制台：项目文件、训练与命令任务、持久终端、设备指标和现有 Codex 桌面会话入口。

本项目已停用，作者改用 Codex 官方远程连接。本仓库用于保存源码与设计，不代表仍在运行或持续维护。

## 归档内容

- React 19 + TypeScript + Vite 前端，白色与蓝色界面，包含手机原型和真实手机入口。
- Node.js + Express 后端、SQLite 元数据存储、WebSocket、node-pty 持久终端。
- 命令任务队列、日志、结构化训练指标、工作流、文件上传和项目浏览。
- Windows 启动/停止/登录自启脚本，以及 Tailscale/Clash 分流示例。
- 单元与集成测试、原始总体方案、设计参考图。

不包含运行数据库、配对码、登录凭据、真实桌面会话、日志、上传资料、依赖缓存或构建产物。没有将用户已有训练工程、模型和数据集纳入归档。

## 历史验证与限制

归档前通过 TypeScript、双入口生产构建、28 个模板文件完整性检查，以及 14 项后台验收、7 项桌面连接器单元测试和 1 项桌面接口夹具集成测试。用户曾从手机跑通模拟训练任务。

桌面连接器使用当时桌面应用内置的本机 App Tools 管道，是依赖具体桌面版本的实验实现，不是官方稳定的第三方远程 API。真实桌面读取验证过；夹具测试不等于真实写入测试。数据库与实际会话绑定均未归档，连接器默认未配置。请使用官方远程连接满足日常桌面会话需求。

没有实现完整 Docker 管理、多主机调度或外部训练进程接管。`docs/总体方案.md` 是规划记录，不能据此认定所有规划功能已经完成。

## 从源码恢复

需要 Node.js 24、npm；终端功能依赖 node-pty 的平台构建条件。在 Windows PowerShell 中运行：

```powershell
npm ci
npm run build:all
.\start-console.cmd
```

真实界面为 `http://127.0.0.1:8787/app/`，原型预览在 `/`；执行器使用回环地址 4175。首次启动会新建 `data/` 和新的配对密钥。恢复源码本身不会启用 Windows 登录自启、安装 Tailscale，或修改 Clash。

如另行配置手机网络入口，应重新设置私网和认证；本归档不包含原电脑的域名、地址或网络身份。`scripts/clash-tailscale.js` 仅为参考配置，不会自动执行。

## 目录

- `src/`：前端与手机模板运行时。
- `server/`：API、执行器、主机工具与实验桌面连接器。
- `scripts/`：构建检查、启动停止、备份恢复及可选自启工具。
- `tests/`：后台、桌面接口与模板测试。
- `public/`、`native-public/`、`worker/`：静态资源及原型部署运行时。
- `docs/`：总体方案。
